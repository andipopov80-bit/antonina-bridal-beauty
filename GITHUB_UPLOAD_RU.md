# Antonina Bridal Beauty — загрузка в GitHub

Этот архив содержит исходный код актуальной версии сайта **Antonina Bridal Beauty**.

## Что находится внутри

- страницы, тексты и контактные данные сайта;
- мобильная адаптация и стили;
- изображение главного экрана и favicon;
- ссылки на телефон, WhatsApp, Instagram и Google Maps;
- конфигурация проекта и файл зависимостей;
- исходные файлы, необходимые для последующего редактирования и публикации.

Тяжёлые временные папки (`node_modules`, `dist`, `.next`) в архив не включены. Они создаются автоматически при установке и сборке.

## Как загрузить на GitHub через браузер

1. Распакуйте ZIP-архив на компьютере.
2. Откройте [github.com/new](https://github.com/new).
3. В поле **Repository name** укажите, например: `antonina-bridal-beauty`.
4. Выберите **Private**, если исходный код не должен быть доступен всем.
5. Не добавляйте новый README или `.gitignore`: они уже находятся в архиве.
6. Нажмите **Create repository**.
7. В пустом репозитории выберите **uploading an existing file** либо **Add file → Upload files**.
8. Откройте распакованную папку, выделите всё её содержимое и перетащите в окно GitHub.
9. Внизу страницы нажмите **Commit changes**.

Важно: на GitHub нужно загружать **содержимое распакованной папки**, а не сам ZIP-файл. Файл `package.json` должен находиться в корне репозитория.

## Локальный запуск

Необходим Node.js версии **22.13 или новее**.

```bash
npm ci
npm run dev
```

После запуска откройте адрес, показанный в терминале.

## Проверка сборки

```bash
npm run build
```

## Где менять содержимое

- `app/page.tsx` — тексты, разделы, контакты и ссылки;
- `app/globals.css` — дизайн и мобильная версия;
- `app/layout.tsx` — название и описание сайта;
- `public/images/` — фотографии;
- `public/favicon.svg` — значок сайта.

## Важно про публикацию

GitHub хранит исходный код, но сам по себе не публикует этот проект как готовый сайт. Позже репозиторий можно подключить к Cloudflare, Vercel или другому совместимому хостингу. Текущий опубликованный сайт в ChatGPT Sites продолжит работать независимо от этого архива.
